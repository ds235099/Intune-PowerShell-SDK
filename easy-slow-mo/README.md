# Easy Slow-Mo

A personal pace for your own work. You set an hourly allowance in units. Each hour the app releases **2%** of that allowance and keeps the other **98%** queued until later hours. Settings, the queue, the schedule, and release history stay in this browser (`localStorage`). There is no account and no server.

## Run

```bash
cd easy-slow-mo
npm install
npm run dev
```

Open the URL Vite prints, usually http://127.0.0.1:5173.

## Checks

```bash
npm test
npm run build
```
